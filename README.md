# eledger-dist-test

Installere til **eledger**, testmiljøet. Her ligger kun bygget program — ingen kildekode.

## Hent

```
https://eledger-server-test.pragmasoft-dk.workers.dev/hent
```

Linket peger altid på den nyeste testudgave. Det ændrer sig ikke med versionsnummeret.

Windows advarer om «ukendt udgiver», fordi programmet endnu ikke er kodesigneret.
Klik **Mere info → Kør alligevel**.

## Programmet virker ikke uden en nøgle

Første gang du åbner eledger, bliver du bedt om en serveradresse og en adgangsnøgle.
Har du ikke fået dem tilsendt, kan du ikke bruge programmet.

Derfor er denne fil offentlig: at hente den giver ingen adgang til noget som helst.

## Testmiljøet er til afprøvning

Data i test kan blive nulstillet uden varsel. Skal du bruge eledger til noget der
betyder noget, er det [eledger-dist](https://github.com/MortenWesthGit/eledger-dist)
du skal have fat i.
